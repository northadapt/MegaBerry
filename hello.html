Reference

Fonts

Instrument Sans (400, 500, 600, 700) — body, headings, UI. Sans-serif stack fallback: ui-sans-serif, system-ui, -apple-system, Segoe UI, Roboto, Helvetica, Arial.

JetBrains Mono (400, 500) — code blocks, mono labels, stats, timestamps, developer API keys. Monospace fallback: ui-monospace, SFMono-Regular, Menlo, Consolas.

Both loaded via Google Fonts with preconnect hints. No self-hosted fonts.

CSS architecture (7 files + glass-lite, ~292 KB)

All imported through main.css (328 B entry point), which also pulls in assets/vendor/glass/glass-lite.css for the glass-kit buttons:

tokens.css (3.7 KB) — design tokens: colours, type scale, spacing, radii, layout vars. Dark + light mode definitions. Inverse surface overrides.

base.css (3.5 KB) — reset, typography, prose defaults, thin dark scrollbars, and the review-note switch (notes are currently off).

layout.css (6 KB) — grid, container, header, footer, section utilities.

components.css (151 KB) — buttons (glass-kit), dialogs, cards, sidebar, app shell, settings tabs, credits dialog, support tickets, plan badges, all reusable components.

pages.css (114 KB) — page-specific: home hero, studio, pricing, affiliate, feature requests, settings-pricing, trust, hello, plus everything added since: mobile pass, Connect Avatar and training dialogs, Apex Image and tool pages, Outfit Generator, Clear Meta, Downloader, GIF Maker, Fanplace Likes, support polish and sidebar promos. Newer blocks are appended at the end and labelled, so later rules override earlier ones.

docs.css (13 KB) — legal pages: terms, privacy, sidebar TOC navigation.

JavaScript (4 files, ~182 KB)

layout.js (38 KB) — sidebar navigation, expandable sections, pin system (localStorage), dev toggle persistence (mb.devmode), account menu, ⌘K search palette, plan badge updates, theme toggle.

main.js (131 KB) — settings tabs, credits dialog (card/USDC toggle, card payment step), billing MutationObserver for dev mode, receipt dialog with print/PDF, subscription checkout, affiliate opt-in/opt-out/tour/payout settings flows, feature requests (search, filter, suggest), all demo data (invoices, sessions, seats, providers, etc), Connect Avatar dialog, Train Your Own Avatar flow, Intended Output bar.

docs.js (5 KB) — legal page sidebar: scroll spy, mobile TOC dropdown.

tools.js (8 KB) — shared behaviour for the Create and Tools pages: upload zones and counts, mode toggles, pairing and cost maths, steppers, Adv. Settings, seed lock, placeholder results. Loaded only on pages with data-tool.

Apex Image, Outfit Generator, Clear Meta, Downloader, GIF Maker and Fanplace Likes also carry a short inline script each.

All vanilla JS. Zero frameworks, zero npm packages.

localStorage keys

For devs
Key mb.devmode

Dev toggle state: "linked" or "none" (defaults to linked). Persists across all pages. Controls plan badge, credits, billing text, studio state, pricing buttons and the avatar prompts on generator pages.

Key mb.theme

Light/dark theme: "light" or absent (dark default). Read on page load before render to prevent flash.

Key mb.side

Sidebar collapse state: "collapsed" or absent (expanded). Read on page load.

Key mb.pins

JSON array of pinned tool IDs. Rendered in the sidebar "Pinned" section below Overview.

Key mb.nav.open

JSON array of the sidebar sections left open ("Create", "Tools", "Partner Models"). The section holding the current page is always opened as well.
